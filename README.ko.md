# RemoteBridge — 리모드브리지

**내 서버를 이용해 나와 지인의 Windows PC를 연결하는 원격 프로그램입니다.**

[다운로드](https://github.com/BC-0217/RemoteBridge/releases) · [English](README.md) · [서버 설치·설정](docs/SERVER_SETUP.md) · [검증·알려진 문제](docs/VERIFICATION.md)

> **초기 시험판입니다.** 허락받은 PC에서만 사용하세요. TLS로 전송하지만 종단간 암호화(E2E)는 아니므로 **서버 주인은 화면과 입력 내용을 볼 수 있습니다.**

## 서버 ID와 PC ID는 다릅니다

| 항목 | 용도 | 누구에게 받나요? |
|---|---|---|
| 서버 ID / 서버 PW | 어느 서버에 참가할지 정합니다 | 그 서버를 만든 주인 |
| 내 PC ID / 임시 PW | 다른 사람이 이 PC에 연결할 때 사용합니다 | 서버 참가 후 홈에 표시 |
| PC 고정 PW | 임시 PW 대신 계속 사용할 PC 접속 비밀번호 | PC 주인이 직접 설정 |
| 서버 주소 / 인증서 지문 | 실제 HTTPS 서버와 신원을 확인합니다 | 서버 설치를 담당한 주인 |
| 서버 관리키 | 서버 ID/PW·등록 장치를 관리하는 관리자 비밀값 | 서버 설치 시 직접 생성 |

## 지인으로 참가하기

1. 릴리즈에서 **RemoteBridge.exe**를 받습니다. .NET Framework4.8이 설치돼 있어야 합니다.
2. 서버 주인에게 **서버 ID와 서버 PW**를 받습니다.
3. **서버 설정 → 서버 참가**에 입력합니다.
4. 참가 후 홈에 **내 ID / 임시 PW**가 나타납니다. 각 PC는 서버에 등록돼 있어야 합니다.
5. 상대 PC를 제어하려면 **상대 PC ID**와 **상대의 임시 PW 또는 고정 PW**를 입력합니다.
6. PC PW를 비워 두면 상대에게 승인 요청이 뜹니다. 틀린 PW는 연결이 거부됩니다.

**상대 PC도 같은 최신 EXE로 업데이트해 주세요.** 본인의 설정 파일이나 개인키를 EXE와 함께 보내지 마세요.

## 고정 PW와 자동 승인

**PC 접근 설정 → 고정 PW 설정**에서8~128자로 설정합니다. 서버 참가 PW와는 다른 비밀번호입니다. 앱을 다시 실행하거나 서버를 재시작해도 설정은 유지되며, 서버에는 원문이 아닌 소금값을 사용한 검증값을 저장합니다.

기본으로 켜진 **PW가 맞으면 승인 없이 화면·입력 공유 허용** 옵션은 다음과 같이 동작합니다.

| 입력 | 결과 |
|---|---|
| 임시 PW 또는 고정 PW 일치 | 승인창 없이 화면 공유와 마우스·키보드 제어 시작 |
| PW 공란 | 이 PC 주인에게 승인 요청 |
| 틀린 PW | 오류 안내·연결 차단 |

자동 접근을 원치 않으면 옵션을 끄세요. 옵션이 꺼졌거나 서버가 자동 접근을 지원하지 않으면 직접 승인해야 합니다. **프로그램이 실행 중일 때만** 연결할 수 있습니다. 이미 연결된 상대를 끊으려면 **공유 중지**를 누르세요. PW 변경만으로 기존 연결이 종료되지는 않습니다.

## 화면·입력·최근 기록

- 마우스 클릭·누른 상태 유지·드래그·휠과 키보드 Ctrl/Shift/Alt 조합을 지원합니다.
- 최근 기록에는 실제 연결에 성공한 **상대 PC ID**를 최신순으로 표시합니다.
- 같은 서버/인증서/상대 ID는 한 줄로 갱신하며, 더블클릭하면 상대 ID를 채웁니다.
- 연결 비밀번호는 최근 기록에 저장하지 않습니다.
- 서버 입력 기억은 현재 Windows 계정의 DPAPI로 암호화합니다. 다른 PC에 설정을 복사하는 방식은 지원하지 않습니다.

## 서버를 만드는 주인

**서버 만들기 버튼이 AWS 서버를 자동으로 설치해 주지는 않습니다.** 먼저 [서버 설치 안내](docs/SERVER_SETUP.md)에 따라 HTTPS 서버·인증서·개인 관리키·영속 저장소를 준비해야 합니다.

설치된 서버 주소와 지문으로 연결을 확인한 뒤, 해당 서버의 관리키로 인증하고 공유할 서버 ID/PW를 만듭니다. 만든 PC도 원격 연결에 참여하려면 별도로 서버에 참가해야 합니다.

EXE에는 공개 시험용 이름 조회 서버의 URL·인증서 지문이 들어 있습니다. 이는 비밀번호가 아니지만, 다운로드만으로 누구나 무료 서버를 사용하거나 새 서버를 자동 등록할 수 있다는 뜻은 아닙니다. 자체 조회 서버를 사용한다면 신뢰할 수 있는 bootstrap 설정을 따로 배포해야 합니다.

## 요구 환경·주의사항

- Windows 클라이언트: .NET Framework4.8 필요. Windows7 SP1 지원을 목표로 하지만 **실제 Win7 실행 검증은 미완료**입니다.
- 서버: .NET10 ASP.NET Core 런타임. 클라이언트와 서버의 런타임은 다릅니다.
- 단일 EXE는 런타임까지 포함한 설치 파일이 아니며, Windows 서비스·UAC 우회 기능도 아닙니다.
- 현재 UI는 주로 한국어입니다.
- 별도 물리 PC 두 대의 자동화 검증, 무끊김·입력 무손실, 장기 부하 용량은 보장하지 않습니다.
- 성능 측정 이후 단일 문자 입력이 누락된 경우가2회 있었으며 원인은 미확정입니다. 별도 AWS 핵심 입력 시험은 통과했지만 이 문제를 해결 완료로 처리하지 않았습니다.
- 오디오·파일 전송·클립보드 동기화·완전한 IME 지원은 없습니다.
